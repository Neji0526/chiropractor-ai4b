# Chiropractor Website — SEO & Content Prompt

Create useful, human-sounding content for a local chiropractic practice.

## Goals
- Improve local search visibility
- Explain services clearly
- Build trust
- Encourage qualified appointment inquiries

## Content Types
Create/edit CMS content for:
- Homepage
- Service pages
- Condition pages
- Practitioner pages
- Location pages
- FAQs
- Blog/resources

## Local SEO
Support location-aware phrases naturally, such as:
- chiropractor in [CITY]
- chiropractic clinic in [CITY]
- back pain chiropractor in [CITY]
- neck pain chiropractor in [CITY]

Do not keyword-stuff.

## Metadata
Every indexable page should support:
- SEO title
- Meta description
- Canonical URL
- Open Graph data

## Structured Data
Implement appropriate structured data when factual information is available:
- LocalBusiness / appropriate healthcare business type
- BreadcrumbList
- FAQPage when eligible
- Article for blog posts

## Writing Rules
Content must sound like it was written for the actual clinic.

Use clear everyday language.

Do not:
- Invent credentials
- Invent testimonials
- Invent statistics
- Guarantee medical outcomes
- Diagnose visitors
- Make unsupported medical claims

Use editable placeholders when clinic-specific facts have not been provided.
